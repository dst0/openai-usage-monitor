Section 1

⚙️ How It Works

Architecture and interplay of the Rust core, native macOS menu bar app, and OpenAI Codex.

🦀

Ultra-lightweight Rust Core

Consumes only ~3 MB RAM. On every CLI execution, pre-flight checks complete in ≤ 1 millisecond, seamlessly wrapping OpenAI Codex with zero memory overhead.

🛡️

Atomic Locks for Swarms

When dozens of agents run in parallel, cross-process file locking (fs2 flock) guarantees zero race conditions, JSON corruption, or token collisions in ~/.codex/auth.json.

⏳

Smart Auto-Switch Policies

Intelligent rotation using the Reset-First algorithm, prioritizing accounts with available Reset Credits, and supporting Business-Only and Business-Priority modes with preemptive return on quota restore.

🔄

Automated Thread Resumption

Two-phase detection scans locks and state_5.sqlite to unpause rate-limited threads across switches, dispatching queue messages and triggering macOS Accessibility unpauses.

🔌

Transparent CLI Shim

cxi install-shim configures ~/.local/bin/codex to wrap Codex CLI commands transparently, auto-switching before quota depletion without modifying scripts or IDE configs.

🍎

Native Menu Bar App

Built with Swift (AppKit), featuring anti-vibrancy composite rendering for inactive displays, 3D 3-tier shield badges, 10 languages, and real-time quota telemetry.

Section 2

🚀 Getting Started

Step-by-step setup, adding OpenAI accounts, and configuring automatic rotation.

Step 1. Capture Your First Account

If already logged in to OpenAI Codex in terminal, save the active session from ~/.codex/auth.json:

Terminal
$ cxi save-current main
# Or launch interactive wizard:
$ cxi setup

Step 2. Add Second & Additional Accounts

Run cxi add <account-id> or choose option 2 in cxi setup. It triggers official OpenAI browser OAuth login via codex login and securely stores credentials with 0600 permissions. Authenticate only once!

Step 3. Install macOS Menu Bar App

Build and install the native app to /Applications/Codex Monitor.app with one command:

Terminal
$ ./scripts/install.sh

A sleek status bar icon with 3D shield badges will appear in your macOS menu bar.

Step 4. Enable Transparent System Shim

Allow IDEs, external agent frameworks, and scripts to leverage quota protection automatically:

Terminal
$ cxi install-shim
# Seamlessly wraps standard codex invocations

💻 How To Use

CLI command reference and status bar menu actions.

CLI Command Description When To Use
cxi status Show quota table: 5H sprint, 7D limit, plan multiplier, and credits Quick overview of quotas and reset timers in terminal
cxi switch <id> Switch active account and automatically resume interrupted turns Manual rotation to specific account
cxi resume [id] Resume active or rate-limited thread via Codex socket & AXUIElement Unpausing turns halted by rate limits or errors
cxi config Configure auto-switch (business-only, business-priority) & app restart Customizing autonomous rotation behavior
cxi set-multiplier <id> <n> Override account plan multiplier (e.g. 20 for Pro 20x, 5 for Business) Calibrating quota display to actual plan capacity
cxi reset-multiplier <id> Reset multiplier override back to auto-detected default Restoring standard plan scaling
cxi setup Interactive wizard for adding, verifying, and managing accounts Initial configuration or managing multiple accounts
cxi add <id> Add new account via browser OAuth login (codex login) Registering another OpenAI account
cxi wrap <cmd> Execute command with pre-flight quota check and auto-switch Running unattended commands and autonomous scripts

📊 Reading Metrics & Indicators

Complete breakdown of numbers, color thresholds, and 3D shield badges.

macOS Status Bar Title

[Codex] 5H: 96% · W: 94% [ 🛡️ 🛡️ ]

Each element conveys critical information:

  • [Codex Logo]: Official icon with anti-vibrancy composite rendering on inactive displays.
  • 5H: 96%: Remaining quota for active account's primary 5-hour rolling sprint window.
  • W: 94%: Remaining quota of the secondary 7-day Weekly Limit Pool.
  • [ 🛡️ 🛡️ ]: 3D Stratified Shield Badges — one badge per configured account:
    • Top Tier (7.5 pt): 5-Hour sprint quota linear gradient.
    • Middle Tier (5.8 pt): 7-Day weekly pool quota (overrides top tier to gray if depleted).
    • Bottom Strip (3.2 pt): Rate-Limit Reset Credits indicator (Green when credits > 0).
    • Outer Rim (0.6 pt): Crisp dark perimeter stroke ensuring high contrast against light or dark wallpapers.
🎨

Indicator Color Scale

🟢 Green > 50% — High quota headroom, fully operational.
🟡 Yellow 20% – 50% — Moderate remaining quota, actively draining.
🔴 Red < 20% — Critical limit. Features soft red omnidirectional shadow for contrast. Automatic switch triggers at ≤ 0% (or 429).
⚫ Gray Exhausted / Depleted — Quota drained, weekly pool empty, or re-authentication required.
