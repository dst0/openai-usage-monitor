Section 1

⚙️ How It Works

Architecture and interplay of the Rust core, native macOS menu bar app, and OpenAI Codex.

🦀

Ultra-lightweight Rust Core

Consumes only ~3 MB RAM. On every CLI execution, pre-flight checks complete in ≤ 1 millisecond, and execvp replaces the process with OpenAI Codex with zero memory overhead.

🛡️

Atomic Locks for Swarms

When dozens of agents run in parallel, cross-process file locking (fs2 flock) guarantees zero race conditions, JSON corruption, or token collisions.

⏳

Reset-First Strategy

Instead of random rotation, the switcher picks the account whose quota resets soonest. As you consume quota, the reset timer elapses. When empty, the system switches to the next while the previous regenerates to 100%.

⚡️

Pre-emptive Switch at ≤ 5%

Complex reasoning queries can consume 2–4% quota in one turn. Rotation triggers early when ≤ 5% remains, preventing task failures from HTTP 429 Resource Exhausted.

🔌

Transparent System Shim

cxi install-shim enable replaces agy with our 3 MB wrapper while preserving Google's binary as agy-real. Built-in recursion guards eliminate infinite loops.

🍎

Native Menu Bar App

Built with Swift (AppKit), full dark/light theme support, 9 languages, and WMO optimization. Real-time quota status without UI lag.

Section 2

🚀 Getting Started

Step-by-step setup, adding Google accounts, and launching rotation.

Step 1. Capture Your First Account

If already logged in to OpenAI Codex in terminal, capture the session as your primary account:

Terminal
$ cxi capture-current
# Or launch interactive wizard:
$ cxi setup

Step 2. Add Second & Additional Accounts

Choose option 2 in cxi setup. It opens a browser window for standard Google OAuth, captures the refresh_token, and stores credentials in macOS Keychain with 0600 permissions. Authenticate only once!

Step 3. Install macOS Menu Bar App

Build and install the native app to ~/Applications with one command:

Terminal
$ ./scripts/install.sh

A stylish status bar icon with split circles will appear in the macOS menu bar.

Step 4. Enable Transparent System Shim

Allow IDEs, external agents, and scripts to use rotation without changing the standard agy command:

Terminal
$ cxi install-shim enable
# Check shim status:
$ cxi install-shim status

Section 4

📊 Reading Metrics & Indicators

Complete breakdown of numbers, color thresholds, and 3D split circles.

macOS Status Bar Title

[Codex] 5H: 96% · W: 94% [ ◐ ◐ ]

Each element conveys critical information:

  • [Codex Logo]: Codex icon.
  • 5H: 96%: Remaining limit for active account's 5-hour rolling sprint.
  • W: 94%: Remaining limit of overall Weekly Pool.
  • [ ◐ ◐ ]: 3D glossy split circles — one circle per configured account:
    • Left Half (5H): Shows account's 5-hour sprint quota.
    • Right Half (W): Shows account's weekly pool quota.
🎨

Indicator Color Scale

🟢 Green > 50% — High quota headroom, fully operational.
🟡 Yellow 20% – 50% — Moderate remaining quota, actively draining.
🔴 Red < 20% — Critical limit. Automatic switch occurs at ≤ 5%.
⚫ Black Error / Expired — Re-authentication required via cxi setup.
📋

Status Bar Dropdown Menu

  • WEEKLY POOL: Shows pool progress bar and countdown to weekly reset (Sunday 23:59).
  • ACCOUNTS: [ACTIVE IN CLI] — current dispatch slot; [RESERVE #2] — backup account ready to take over.
  • 5h-sprint: Sprint progress bar with (reset in 1h 20m) or (ready to take over) at 100%.
  • Models: Individual quotas for models (GPT-5.5, Flash, GPT-5.4).
